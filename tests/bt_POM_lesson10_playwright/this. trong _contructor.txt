Dùng this. trong constructor để làm gì?
Khi viết automation test với Page Object Model (POM), bạn thường có một class đại diện cho một trang web.
Trong constructor, bạn sẽ truyền vào đối tượng page của Playwright để sử dụng lại nhiều lần.

Ví dụ:
import { Page } from "@playwright/test";

export class LoginPage {
  private page: Page;

  constructor(page: Page) {
    this.page = page; // gán giá trị page từ bên ngoài vào thuộc tính page trong class
  }

  async login(username: string, password: string) {
    await this.page.fill('#username', username);
    await this.page.fill('#password', password);
    await this.page.click('#loginBtn');
  }
}
👉 Ở đây:
Thành phần	            Giải thích
constructor(page: Page)	Là hàm khởi tạo, nhận đối tượng page từ Playwright.
this.page = page	    Gán giá trị page truyền vào thành thuộc tính page của class.
this.page.fill(...)	    Dùng page đó để thao tác với các element trong class.
Trong cùng class:
Dùng this.tênHàm hoặc this.tênBiến để gọi tới method hoặc property của class hiện tại.
Trong class con kế thừa class cha (extends):
Dùng this.tênHàm hoặc this.tênBiến để gọi tới method hoặc property của class cha, miễn là chúng public hoặc protected.
Nếu bạn muốn gọi constructor hoặc method bị ghi đè của class cha, thì bạn phải dùng super thay vì this.
